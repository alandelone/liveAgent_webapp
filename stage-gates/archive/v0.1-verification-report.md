## Scope correction

The previous report described FEAT-006 as a complete streaming audio pipeline and FEAT-007 as complete VAD-driven barge-in. Repository inspection later established that:

- The browser used `SpeechRecognition` and `AnalyserNode`; it did not send AudioWorklet PCM.
- The Python bridge discarded incoming binary audio.
- Playback timing was simulated and no audible TTS audio was generated.

The original test run remains useful regression evidence for the UI prototype, but its broad voice-pipeline conclusion is superseded by the v0.2 feature list and current stage gates.
