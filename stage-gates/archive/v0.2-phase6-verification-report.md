The response stopped without cancelling background task completion. A previously measured explicit local interruption stopped the worklet in 0.200 ms. Both are below the 300 ms requirement.

The investigation also fixed two production defects exposed by this proof:

1. `USER_SPEECH_START` is now emitted before cold ASR initialization and before `TTS_END(INTERRUPTED)`, so response audio stops immediately and clients can measure the correct boundary.
2. Qwen ASR is prewarmed once at service startup and its model is shared with serialized inference across sessions; new browser connections no longer create duplicate GPU engines.
